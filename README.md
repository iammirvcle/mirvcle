## What’s inside (solutions you can deploy)

### BUSINESS Kits (client-ready)
- **Cyber Insurance Readiness** — One-button controls report (MFA/AV/firewall/patch/backup) + prioritized remediation.
- **Access Review Snapshot** — Azure AD roles/groups, stale users, and local admins; flags high-risk accounts for cleanup.
- **Backup & Restore Drill** — Backup → restore sample → hash-verify; records **RPO/RTO** for audit.
- **Cost Guard (Azure + AWS)** — Budgets/alerts, tag governance, and idle resource findings to cut waste.
- **Device On/Offboarding** — Standardized build (apps, BitLocker keys, inventory), plus secure wipe and access revocation.
- **WEF Starter (No SIEM)** — Windows Event Forwarding to a central collector + daily failed-logon digest.

## Quick start (how clients use these)

Most kits are designed to run with **PowerShell** and standard cloud consoles:

1. **Clone or download** this repo.
2. Open the kit folder under `BUSINESS/`.
3. Follow the **Runbook** in that kit’s `README.md` (steps, screenshots to capture, expected outputs).
4. Deliver the **Outputs/Findings** to stakeholders and apply the included remediation checklist.

**Prereqs (common):**
- Windows PowerShell 5.1+ or PowerShell 7.x  
- Admin rights (for device audits)  
- Optional: Azure CLI / AWS CLI for cloud guardrails
